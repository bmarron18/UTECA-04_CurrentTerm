** Verify that "pip" is installed and updated (pip is a Python package manager) **
	- pip should already be installed with Python 3.13.7
	- Open a terminal and go to the top of the filesystem
		> cd\
		
	- Check for the version of pip installed
		> pip --version		<== Windows
		$ pip --version		<== Linux
			pip 25.2 from /home/bmarron18/.local/lib/python3.10/site-packages/pip (python 3.10)
			
	- Ensure pip is upgraded
		> python -m ensurepip --upgrade			<== Windows
		$ python3 -m pip install --upgrade pip		<== Linux
	
	- If needed, follow the instructions in this website
		https://phoenixnap.com/kb/install-pip-windows
	
** Install Spyder **
	- Go to https://www.spyder-ide.org/
	- Spyder will automatically detect your OS and suggest a download
	- define simple location for Spyder install. For example
		/home/bmarron/spyder-6								<== Linux and Mac OS
		C:\Users\<username>\AppData\Local\Programs\spyder-6		<== Windows
		
** Review Windows filesystem operations snippets **
	- Open the file, "API_Installations_Windows-Basics.py" in Spyder-6
	- Review the information (snippets) in the large-window on the left-hand side
	- Start at [Command Line Operations in Windows] and scroll all the way through the document

** Find the version of Python running in Spyder-6 **
	- Locate the IPython Interpreter mini-window in the lower right-hand corner of Spyder-6
	- Scroll to the top of the mini-window to find the Python distribution (distro) information
	- Something like
		Python 3.11.0rc1 (main, Aug 12 2022, 10:02:14) [GCC 11.2.0]
		Type "copyright", "credits" or "license" for more information

** Check the installation of Spyder-6
	- Open a terminal and go to your home directory
		$ cd ~							<== Linux and Mac OS
		> cd %homedrive%%homepath%			<== Windows
		> cd C:\Users\<your_user_name>\
	
	- Check / find the Spyder installation directory (folder)
		$ find ./ -name "*spyder*" -type d			<== Linux and Mac OS
		> dir /b/s *spyder*						<== Windows
		> where spyder*

** Install the "virtualenv" package (Python) into Spyder directories using pip **
	- Open a terminal
	- Install "virtualenv" in a specific location in Spyder
		> pip install --target C:\Users\<user-name>\AppData\Local\spyder-6\Scripts virtualenv
		$ pip install --target /home/bmarron18/virtualenv virtualenv

      - Verify the installation and locate the executable file
		C:\> dir /b/s virtualenv.exe
			C:\Users\<you>\AppData\Local\spyder-6\Scripts\virtualenv.exe
